Create a simplified Tetris game called "Simple Tetris" on a grid 10 columns wide and 20 rows tall. Blocks are drawn as plain coloured squares, one colour per piece shape; do not generate any image assets, use solid colours only. Use exactly four piece shapes: the square (2x2), the line (4 in a row), the L-shape, and the T-shape. A new random piece of one of these four shapes spawns at the top-middle of the grid. The piece falls downward automatically at a constant rate. Left arrow moves the falling piece one column left, Right arrow moves it one column right, and Down arrow moves it down one row immediately (soft drop); none of these move the piece through the grid walls or through blocks already locked in place. Up arrow rotates the piece 90 degrees; if the rotation would overlap the walls or locked blocks, ignore that rotation press instead of applying it. When a piece can no longer move down because the row below is blocked or it has reached the bottom row, it locks in place at its current position and a new random piece spawns. Whenever a horizontal row is completely filled with locked blocks, clear that row, move every row above it down by one, and add 100 to the score. Show the current score in the top-right corner of the window at all times. If a new piece spawns and immediately overlaps an already-locked block, the game is over: show GAME OVER and the final score, and stop spawning new pieces. Press R to restart with an empty grid and score 0. Press Escape to quit. Print a line to the console every time a control takes effect: MOVE LEFT, MOVE RIGHT, SOFT DROP, ROTATE, RESTART and QUIT, and print GAME OVER when the game ends. No sounds. Keep it to as few files as possible. Use Godot for this
