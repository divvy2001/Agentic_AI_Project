# Kitty Catch

## Spec

Create a tiny one-screen catching game called "Kitty Catch". A cartoon cat at the bottom of the window moves left and right with the arrow keys and stops at the screen edges. Fish fall from random spots at the top; catching a fish with the cat adds 1 point. If 3 fish reach the bottom without being caught, the game is over. Generate exactly two small image assets: the cartoon cat and the fish. Use a plain light-blue background colour instead of a background image. Show the score and missed fish in the top-left corner. When the game is over, show GAME OVER and the final score and stop the falling fish. Press R to restart with score 0 and Escape to quit. Print a line to the console every time a control takes effect: MOVE LEFT, MOVE RIGHT, RESTART and QUIT, and print GAME OVER when the game ends. No sounds. Keep it to as few files as possible.
