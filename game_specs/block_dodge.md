# Block Dodge

## Spec

Create a tiny one-screen dodge game called "Block Dodge". A blue square at the bottom of the window moves left and right with the arrow keys and stops at the screen edges. Red squares fall from random spots at the top; if one touches the blue square the game is over. Each red square that reaches the bottom adds 1 point. Show the score in the top-left corner. When the game is over, show GAME OVER and the final score and stop the falling squares. Press R to restart with score 0 and Escape to quit. Print a line to the console every time a control takes effect: MOVE LEFT, MOVE RIGHT, RESTART and QUIT, and print GAME OVER when the game ends. Use plain coloured squares only; no images or sounds. Keep it to as few files as possible.
